# UI Responsive Tester Skill

Esta habilidad profesional proporciona directrices para auditar y garantizar la adaptabilidad responsiva del frontend en todo tipo de pantallas.

## Puntos de Auditoría Visual e Interfaz

1. **Breakpoints y Diseños Fluidos**:
   - Verificar la adaptabilidad en pantallas móviles (375px a 480px), tablets (768px a 1024px) y escritorios (1280px+).
   - Asegurarse de que las tablas utilicen contenedores con scroll horizontal (`table-responsive`) para evitar desbordamientos de pantalla en smartphones.

2. **Tipografía y Componentes UI**:
   - Garantizar el uso de tokens de diseño globales y paletas armónicas (`var(--primary)`, `var(--bg-body)`, etc.).
   - Verificar que los botones e inputs en pantallas táctiles tengan un tamaño mínimo de toque adecuado (mínimo 44px de alto) para facilitar su interacción en teléfonos o computadoras POS táctiles.
