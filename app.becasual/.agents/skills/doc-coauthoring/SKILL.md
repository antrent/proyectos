# Doc Co-authoring Skill

Esta habilidad establece las mejores prácticas para mantener la documentación del proyecto **BeCasual POS** actualizada, clara y estructurada.

## Estándares de Documentación

1. **Estructura en Markdown**:
   - Usar encabezados jerárquicos claros (`#`, `##`, `###`).
   - Incluir bloques de código con resaltado de sintaxis (`bash`, `javascript`, `sql`, `json`).
   - Utilizar tablas para comparar parámetros o configuraciones.

2. **Mantenimiento del Changelog**:
   - Documentar cada cambio significativo en una sección de cambios con la fecha local, versión semántica y descripción del impacto en el sistema.

3. **Guías de Uso y Solución de Problemas**:
   - Proveer instrucciones paso a paso con comandos ejecutables directamente por el usuario.
